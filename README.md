# arima_pairs
Volatility-aware time series forecasting on S&amp;P 500 pairs using ARIMA and GARCH — foundation for a regime-filtered pairs trading strategy.

This project explores ARIMA-based forecasting and GARCH volatility modelling on S&P 500 stock spreads, using the Kaggle 5-year dataset. It covers the full pipeline: exploratory data analysis, feature engineering, stationarity testing, rolling ARIMA forecasts, GARCH residual modelling, and signal evaluation. Built as the groundwork for a larger pairs trading system that uses volatility regimes to filter mean-reversion signals — trading only when conditions are favourable and sizing down when risk is high.
